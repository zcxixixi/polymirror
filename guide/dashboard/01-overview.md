## 产品概览

PolyMirror 是运行在本地或私有 VPS 上的 **自托管 Polymarket 跟单引擎**（**不是**多租户 SaaS）。Dashboard 是同机的 **本地管理控制台**，用于配置 Leader、查看持仓与 PnL、切换 Preview/Live，无需手改 `config.yaml`。

产品边界：[PRODUCT_SCOPE.md](../PRODUCT_SCOPE.md)。

### 核心能力

| 能力 | 说明 |
|------|------|
| 多 Leader 跟单 | 同时跟踪多个地址 / 用户名 |
| 多账户 | 同一运营商的多个自有钱包（≠ 多租户） |
| Preview 模拟 | 默认不真实下单，先观察再实盘 |
| 策略缩放 | 按比例 / 固定金额 / 自适应 |
| 风控 | 日限额、Kill Switch、单笔上下限、紧急停止跟单 |

### Dashboard 能做什么 / 不能做什么

| 能做 | 不能做 |
|------|--------|
| 添加 / 编辑 Leader 与策略 | 代替 Polymarket 官网手动下单 |
| 管理本机多钱包账户 | 托管私钥、多租户云登录、代运维 |
| 查看 PnL、持仓、审计日志 | 跨平台（Kalshi 等）跟单 |
| Preview ↔ Live、紧急停止跟单 | 保证收益或代持仓 |

## 推荐使用流程

按以下顺序操作，符合大多数用户从试跑到实盘的习惯：

```
① 安装启动 → ② 配置钱包 → ③ 添加 Leader → ④ Preview 观察
       ↓
⑤ 调整策略与风控 → ⑥ 确认活动流正常 → ⑦ 切换 Live（小额）
```

| 阶段 | 对应页面 | 目标 |
|------|----------|------|
| ① 安装启动 | — | 引擎与 Dashboard 正常运行 |
| ② 配置钱包 | **我的账户** | 私钥、Proxy 地址正确 |
| ③ 添加 Leader | **发现 Trader** / **Leader 管理** | 至少 1 个启用的 Leader |
| ④ Preview 观察 | **总览** / **活动流** | 确认有 DETECT / COPY 记录 |
| ⑤ 调整策略 | **Leader 管理** / **设置** | 比例、限额、轮询间隔 |
| ⑥ 排查异常 | **活动流** | 查看 SKIP 原因 |
| ⑦ 实盘 | **总览 / 风控页头** 或 **设置 → 模式** | 二次确认后开 Live |

> **建议：** Preview 至少运行数天，确认跟单逻辑符合预期后再开 Live，并使用 **专用小额钱包**。紧急停跟用页头「停止跟单」（切回 Preview 并关闭 `enable_copy_trading`），不必先停进程。

## 界面结构

侧边栏按 **工作台 / 交易 / 系统** 三组排列，与控制台导航一致：

| 分组 | 页面 | 用途 |
|------|------|------|
| **工作台** | **总览** | 运行状态、今日绩效、轮询引擎、最近活动 |
| | **活动流** | 跟单决策审计（DETECT / SKIP / COPY） |
| **交易** | **发现 Trader** | Polymarket 排行榜、一键加 Leader |
| | **Leader 管理** | Leader 列表、策略、启停 |
| | **持仓** | 引擎 SQLite 跟踪的跟单持仓 |
| | **订单** | Pending GTC 限价单、撤单 |
| **系统** | **我的账户** | 钱包资料、PnL、多账户管理 |
| | **风控** | Kill Switch、跟单开关、限额进度 |
| | **设置** | 全局参数、代理、Preview/Live |
| | **操作文档** | 本帮助中心 |

主内容区上方还有 **全局状态栏**（有告警或 Live 时才显示），以及侧边栏顶部的 **账户切换器**。

### 全局状态栏

主内容区顶部常驻条，有需要时出现，例如：

| 提示 | 含义 |
|------|------|
| 引擎未连接 | daemon 未运行或 API 不可达 |
| Kill Switch 已激活 | 今日暂停跟单 → 前往风控 |
| 最近错误 | 轮询 / 下单异常摘要 |
| 持仓偏差 | 引擎跟踪与钱包不一致 → 查看持仓 |
| Live 模式 | 真实资金跟单中，可一键切回 Preview |
| 有新版本 / 更新进度 | 可选自更新或回滚（GitHub Release） |

### 账户切换器

侧边栏顶部的 **账户下拉框** 决定当前操作上下文：

- 所有页面数据（Leader、持仓、统计）按所选账户隔离
- 切换账户后页面会刷新
- 每个账户有独立的 SQLite 与 `.env` 钱包变量

## 总览页

**路径：** 侧边栏首页（总览）

页头显示当前账户名、Preview/Live 徽章、Kill Switch 徽章、引擎运行时长，以及快捷操作：

| 操作 | 说明 |
|------|------|
| 切换 Live / Preview | 与风控、设置中的模式切换相同，需二次确认 |
| 停止跟单 | 切回 Preview 并关闭跟单开关；Live 下会先尝试清理挂单 |

### 页面区块

| 区块 | 内容 |
|------|------|
| **全部账户** | 多账户时展示各账户今日成交额、跟单笔数、启用 Leader（单账户时隐藏） |
| **今日绩效** | 跟单笔数、成交额、已实现 PnL、Pending GTC、启用 Leaders、上轮跟单数 |
| **24h 跟单活动** | 近 24 小时 COPY / SKIP / ERROR 分布柱状图 |
| **轮询引擎** | 上次轮询时间、拉取 / 跟单 / 跳过 / 挂单成交 / 错误、当前 DB 路径 |
| **最近活动** | 最近审计事件表，可跳转活动流查看全部 |

日常巡检建议：总览确认健康 → 活动流看决策 → 持仓 / 订单看结果。更细的说明见 [监控](05-monitoring.md)。
